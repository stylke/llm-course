# 作业一：用人民日报语料训练 n-gram 语言模型

## 1. 实验内容与数据处理

按照 L1 课件第125页的要求，我用 KenLM 训练了二元、三元和四元词级语言模型，比较训练时间，并用不同参数续写“在阳光明媚的五月，我们学校胜利召开了”。语料使用项目中的“人民日报语料/1998-上半年-带音”六个月份文件。

本次作业的代码、报告和实验记录见 [llm-course 仓库的 hw1 目录](https://github.com/stylke/llm-course/tree/main/hw1)。

这些文件已经分好词，采用 GB18030 编码。清理时保留原有词边界、标点和停用词，删除行首新闻编号及95,087处 `{shang5}` 这类读音标注，将10,587个 `〓` 当作文本边界，再按句末标点切句。检查发现，这个版本没有 `/n` 一类词性标签，因此没有额外做词性剥离。另有5行含编码异常，整行舍弃，具体位置保存在 [数据清理记录](results/data_stats.json)。

为什么要去掉标签？因为这里要学习的是正文中词语怎样接续。如果保留编号，模型可能生成新闻编号；如果保留读音，同一个词会被拆成不同形式，计数也会更稀疏。但原有分词空格需要保留，它决定了词级模型的计数单位。

数据按月份划分：1—4月训练，5月验证，6月测试。同一篇报道不会跨集合。按时间顺序对完全相同的分词句子去重，只保留首次出现者，共去掉12,171个重复句子。另去掉2,423个不足两个有效词的短片段。

| 集合 | 句数 | 词数（含标点，不含句界符） | 低频词/未登录词映射比例 |
| --- | ---: | ---: | ---: |
| 训练集 | 189,081 | 4,754,232 | 1.06% |
| 验证集 | 48,922 | 1,233,489 | 2.29% |
| 测试集 | 48,624 | 1,236,886 | 2.27% |

词表仅由训练集建立，保留出现至少两次的63,517个词，其余词统一映射为 `__RARE__`。验证、测试沿用同一词表，不向训练集补词。这个占位符避开了 KenLM 的保留符号。

## 2. 模型与训练过程

依据课件第113—120页，n-gram 用最近的 (n-1) 个词近似完整上下文：

$$
P(w_1,\ldots,w_T)\approx\prod_{t=1}^{T}P(w_t\mid w_{t-n+1},\ldots,w_{t-1}).
$$

单纯按频数估计时，未见组合的概率为零。补充统计发现，测试集中未见过的二元、三元和四元预测事件分别占19.11%、56.40%和78.76%（包含句尾事件）。如果直接使用未平滑的最大似然估计，三种模型的整套测试集困惑度都会是无穷大。

因此使用 KenLM 0.3.0 默认的插值改进 Kneser–Ney 平滑。它对计数做折扣，并用低阶分布补充概率。低阶分布考虑不同上下文中的续接情况，而不只看词频。本次不剪枝，排序内存预算统一为512 MiB。

运行环境为 macOS、ARM64、Python 3.9.6。每种阶数连续训练3次，计时从启动 `lmplz` 到 ARPA 文件写完，取中位数。不包含语料清理、工具安装和二进制转换。

| 模型 | 三次训练耗时 / 秒 | 中位数 / 秒 | 最高阶组合数 | trie模型大小 / MiB |
| --- | --- | ---: | ---: | ---: |
| 二元 | 0.647 / 0.658 / 0.647 | 0.647 | 1,259,748 | 9.03 |
| 三元 | 1.457 / 1.462 / 1.471 | 1.462 | 3,023,329 | 34.08 |
| 四元 | 2.329 / 2.422 / 2.323 | 2.329 | 3,864,963 | 75.20 |

日志显示训练分为计数与排序、调整计数、计算初始概率、插值和写出模型五个阶段，没有神经网络训练中的多轮梯度更新。阶数增加后，需要处理和保存的组合更多，所以耗时和文件大小都增加了。ARPA 转为 trie 二进制另需约0.341、1.436、3.274秒。这些是本机短时运行结果，文件缓存和系统负载会影响耗时。

## 3. 困惑度评测

按照课件第110页，以测试词序列的平均负对数概率计算困惑度：

$$
\mathrm{PPL}=\exp\left(-\frac{1}{N}\sum_i\ln P(w_i\mid h_i)\right).
$$

每句加入句首、句尾标记，句尾计入 (N)，句首不计入。KenLM 返回以10为底的对数，代码据此换算。以下结果都在同一分词和词表下计算，未知词按上述类别合并，属于封闭词表评测，不能理解为能预测具体的未知词。

| 模型 | 验证集PPL | 测试集PPL |
| --- | ---: | ---: |
| 二元 | 329.63 | 337.38 |
| 三元 | 242.75 | 252.09 |
| 四元 | 232.07 | 242.28 |

先按验证集选择阶数，得到四元模型，再报告测试结果。三元相对二元的改善较明显，四元继续下降，但幅度变小。这说明更长的局部上下文有帮助，也说明增加阶数的收益需要和存储成本一起考虑。

## 4. 指定开头的续写

开头按语料习惯切成“在 / 阳光 / 明媚 / 的 / 五月 / ， / 我们 / 学校 / 胜利 / 召开 / 了”，这些词都在训练词表中。每次最多新增60个词，遇句末标点或句尾标记停止。生成时不输出未知词占位符，并对剩余候选重新归一化。

对每个阶数均预设5组参数：贪心、(T=0.7,k=20)、(T=1,k=20)、(T=1,k=100)、(T=1,p=0.9)。温度通过 (P_T(w)\propto P(w)^{1/T}) 调整分布，top-k保留概率最高的k项，top-p保留累计概率达到p的最短候选前缀。本实验的top-p在完整输出词表上计算，不先做top-k。

下表只列固定开头之后的原始续写，随机种子均为42，未人工改写。完整17条输出见 [原始续写结果](results/generations.md)。

| 模型与参数 | 原始续写 |
| --- | --- |
| 二元，T=0.7，k=20 | 一次会议，使我国政府的一次会议的。 |
| 三元，T=1，k=20 | 第十五次全国代表大会胜利召开和香港的繁荣稳定。 |
| 四元，贪心 | 第十五次全国代表大会，是在“文化大革命”中，有一种说不出的高兴。 |
| 四元，T=0.7，k=20 | 。 |
| 四元，T=1，k=100 | 新的活力。 |
| 四元，T=1，p=0.9 | 这些被宣布压锭 |

最后一条由句尾标记结束，原始输出没有句号。三元贪心还出现了“其中包括：一是要有新的一年，是一种”的循环，一直达到长度上限。

这些结果有新闻报道的用词特点，但经常搭配不当。例如“召开了新的活力”在局部概率上能生成，语义上却不成立。“第十五次全国代表大会”也符合当年新闻语料的表达，却不适合接在“我们学校”后面。

降低温度并没有保证句子更完整，四元模型在 (T=0.7,k=20) 时直接生成句号。固定k=20、把温度提高到1后，这次输出变长，但内容仍然混乱。扩大k也没有自动改善质量。对验证集选出的四元模型，另固定种子7和2026生成的结果同样存在语义问题。因此不能只挑一条看起来顺的续写来判断模型效果。

## 5. 体会

四元模型的困惑度最低，但仍然不能围绕校园场景稳定续写。原因在于它预测第一个新词时最多只看“胜利 / 召开 / 了”，“学校”已经落在窗口之外。我还把前文换成“昨天政府”，保持最后三个词相同，检查整个词表上的下一词概率，三种模型的结果都完全相同。这比只看一个续写例子更直接地说明了有限上下文的限制。

这次实验让我看到，平滑能缓解未见组合的零概率问题，增加阶数能改善局部预测，但二者都不能保证模型理解整句话。以后可以比较更高阶模型，或加入校园领域语料，检验主题偏移能否减少。这两项本次没有实际测试。
